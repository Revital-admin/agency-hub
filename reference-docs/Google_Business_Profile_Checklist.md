# Google Business Profile Setup Checklist — Revital Productions

Free, fast, and often outranks paid SEO tools for local discovery. Worth doing before Ahrefs/SEMrush is even on the budget. This same checklist doubles as the delivery methodology for the "Local SEO (Google Business Profile, local citations, NAP consistency)" line already sitting in the Service Pricing Admin catalog — running it on Revital's own listing first is a live test of that offer before pitching it to a client.

## 1. Claim & Verify
- [ ] Confirm the listing is claimed under a Revital-owned Google account (not a personal one that could lose access later)
- [ ] Complete verification (postcard, phone, or email — whichever Google offers)

## 2. Core Business Info (NAP Consistency)
- [ ] Business name matches exactly what's used everywhere else (website, socials, email signature) — no keyword-stuffing into the name
- [ ] Address is exact and matches the website footer and any invoices/contracts
- [ ] Phone number is a real, monitored line — not a placeholder
- [ ] Website URL points to the live site (not a broken or staging link)
- [ ] Hours are accurate, including holiday hours if relevant

## 3. Categories & Services
- [ ] Primary category set to the closest match (e.g. "Video Production Service" or "Marketing Agency" — pick the one prospects would actually search)
- [ ] Add secondary categories for the other real services (e.g. "Advertising Agency," "Video Editing Service," "Event Planner" if live events apply)
- [ ] Fill in the Services section with actual offerings, not just categories — use plain-language names a prospect would search, not internal service-catalog naming

## 4. Photos
- [ ] Logo set as the profile photo
- [ ] Cover photo is a strong, real shot (behind-the-scenes shoot photo works well here)
- [ ] Add 5-10 real photos from actual shoots/events — listings with more photos get meaningfully more clicks and calls
- [ ] Add a short team/office photo if comfortable — profiles with a human face convert better than a purely corporate look

## 5. Description
- [ ] Write the business description in plain language — what Revital does, who it's for ("brands on the rise"), and what makes the approach different (AV production + marketing under one roof)
- [ ] Avoid keyword-stuffing; write for a human reading it, not an algorithm

## 6. Reviews
- [ ] Set up the Google review link (Google Business Profile → Get more reviews → copy the short link)
- [ ] Ask Evry Intention and Reginald White for a Google review, not just a testimonial — a portal testimonial doesn't help local search the way a public Google review does
- [ ] Respond to every review that comes in, good or bad — response rate itself is a ranking factor

## 7. Posts & Updates
- [ ] Publish a Google Post around any major update (new case study, blog post going live, service launch) — these show directly in the listing and cost nothing
- [ ] Treat this as a light-touch addition to the biweekly content cadence already planned, not a separate workstream

## 8. Q&A Section
- [ ] Seed a couple of the Q&A section's likely questions yourself (e.g. "Do you offer live event AV services?" "What's a typical project timeline?") so the section isn't empty when a real prospect checks it

## 9. Ongoing
- [ ] Check monthly: new reviews to respond to, photos to add from recent shoots, hours/info still accurate
- [ ] Revisit this checklist once real local-search traffic exists, to see what's actually driving views/calls vs. what didn't matter
