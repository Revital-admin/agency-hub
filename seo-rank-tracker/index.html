SEO Rank Tracker

Target keywords and their search position over time, across every client. Manual entry, checked against Search Console / Google directly — this doesn't pull rankings automatically, it's just one place to log what you find so nothing drifts unnoticed between SEO Audits.

Why this is manual, not pulled from SEMrush: SEMrush's API is only unlocked on their Business/Advanced plan (~$549/mo, separate from a regular SEMrush seat), and API units are billed on top of that. Even with it, their Position Tracking API doesn't check arbitrary keywords on demand — you'd still have to set up a Position Tracking project per client inside SEMrush's own dashboard first (domain, keywords, location), and the API just reads results from that. So it automates the pull, not the setup. Worth building if the agency ends up on SEMrush Business tier — ask to have it wired up then.
